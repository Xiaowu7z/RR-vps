## 修复内容

- systemd 的 Conditions/Asserts 在这些系统上会返回 `[unprintable]`，或带属性名的同类文本。新增读取适配，通过 D-Bus 获取实际条件并校验类型；没有把无法读取的属性直接当作空值放行。
- 兼容路径监控的“路径 (PathExists)”显示格式。
- 定时器和条件按实际集合核验，避免依赖 systemd 返回顺序；仍检查条目数量、路径与时间设置。
- 测试脚本关闭子进程继承的 SSH 输出描述符，避免后台订阅进程让已完成的测试保持连接。

最初三台安装失败及定位证据：[首次短测](https://github.com/Xiaowu7z/RR-vps/actions/runs/34080842590)、[条件属性](https://github.com/Xiaowu7z/RR-vps/actions/runs/34081297859)、[路径与定时器格式](https://github.com/Xiaowu7z/RR-vps/actions/runs/34083782358)。

三台运行观察实际完成于 04:47–04:48 UTC；后台订阅进程继承测试输出句柄，导致 SSH 没有及时结束。仅重启这三个 RR 订阅 worker 后，公网 TCP 和 SSH 复查成功，工作流正常退出。节点及面板观察结果未因此改写。
