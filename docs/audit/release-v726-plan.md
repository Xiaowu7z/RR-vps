# 7.2.6 正式版整合范围、证据与发布门禁

用户于 2026-09-13 在洛杉矶 7.2.1 服务器恢复成功回执之后明确要求：
“整合修复发布7.2.6正式版。”本次授权覆盖将已确认的问题整合到正式版并完成发布。
本记录据此记录 `owner-approved`，不引用虚构的三机验收、实机升级或额外批准。
正式发布成功仍以实际 GitHub main、Tag、Release、工作流和资产核验为准。

1. `owner-recovery-v724.json` 保持原字节、原 helper 和原 7.2.4 bundle 摘要。
   它证明用户在 Debian 12 上报告的 7.2.3 定向恢复，不证明完整安装 7.2.4。
2. `owner-recovery-la721-20260913.json` 独立记录本次真实洛杉矶恢复回执：
   helper commit `081a6d684a1da440306bb32fd2413c4b2a4e82fb`，
   SHA256 `abafb5c2e652adf998213d9179f5b1c610417aa19c136928cabbedbf2f54b1df`，
   使用 `--repair-loopback`，全部阶段 PASS，最终 `LA721_RECOVERY_COMPLETE`。
   安装仍为带本地健康补丁的 7.2.1，身份保留；IPv4 本机订阅端口 20382
   的精确回环规则与持久化已修复，原外部阻断保留，健康定时器仍禁用。
3. 7.2.6 候选发布包由 `verify-owner-recovery-evidence.py` 的独立版本和摘要常量绑定。
   固定 7.2.5 已发布包及旧 update guard、install-core 是源码范围对比基线，历史回执不改标成新版本。
   候选完整 CI 和源码/产物一致性是当前提交的发布证据，不能转换成实机升级证明。

## 允许整合的代码范围

- 运行版本及安装入口的版本/生成摘要更新。
- 健康检查对已配置跳跃规则只读观察，避免普通菜单/健康检查再次打开写事务。
- 本机订阅回环放行、原外部 DROP 保持、规则校验与新旧配置兼容及升级迁移。
- 防火墙隔离 guard 的持续标记触发问题、严格受管旧版本迁移与服务状态检查。
- 与上述迁移直接相关的事务外部状态快照/回滚和升级恢复处理。
- 安装器同步失败回滚保留并绑定当前候选 runtime，供恢复防火墙 guard 前的所有权校验使用。
- 备份恢复中精确本机订阅规则的受管识别与回放，以及 doctor 修复时先恢复本机路径再启动服务。

候选升级期间公网防火墙策略仍只读。唯一新增例外是精确本机订阅回环规则：
只有真实持锁、完整外部状态快照已封存且通过校验时，才能在候选服务启动前迁移；
提交前不保存持久规则，提交后由既有 finalize 路径持久化，失败则按快照回滚 live 规则。
事故 helper 留下的 `rr-la721-loopback` 作为既有 foreign 规则原样保留；
正式版新规则 `rr-local-subscription` 按完整精确元组纳入受管规则投影和回滚范围。
不会为任意自定义默认 DROP 防火墙自动增补来源端口或 ESTABLISHED 受管规则。
写入前必须证明本机往返路径；不能证明的用户策略在写入前拒绝，不据 LA 默认
ACCEPT 或标准 UFW 的兼容结果宣称支持所有自定义防火墙布局。

实际变更还须符合校验器列出的确切函数边界和最终文件摘要。未经记录的运行载荷
变化即使重新生成了 manifest/bundle 仍拒绝。Cloudflared 7.2.5 修复保持基线字节。
最终构建后才将真实摘要钉入校验器，任何待定摘要均不能通过发布门禁。

## 仍然必须满足的门禁

- `.github/workflows/ci.yml` 对最终 main SHA 完整运行既有 CI、平台矩阵和新增回归。
- `.github/workflows/vps-stability.yml` 保留旧更新器要求的路径，使用
  `--require-approved-policy`，验证两份历史真实回执以及独立的当前候选摘要和限制范围。
  显示名与 summary 明确这是回执/源码核验，不连接退役 VPS，也不声称运行三机测试。
- 现有发布器继续要求同一个 main SHA 的两项最新成功 **push** 记录；
  不能用 `workflow_dispatch`、其它 SHA、父提交或缓存结果替代。
- 不改变 immutable release、annotated tag 所有权、Latest/Tag/main 一致性检查；
  正式资产仍恰好为 `install.sh`、`manifest.sha256`、`rr-bundle.tar.gz`、
  `RELEASE_INFO`、`SHA256SUMS` 五项。
- 发布后读取远端结果核对上述状态及摘要；不在同版本发布后额外推进 main 造成身份不一致。
