📖 权限教程：把防火墙权限交给面板

面板通过 rr --fw-* 命令操作 iptables。若下方权限状态显示异常，按以下步骤在服务器上操作：

1. 确认面板服务以 root 运行：
systemctl show rr-nexus -p User
输出 User=root 即正常。

2. 若不是 root：
sudo systemctl edit rr-nexus，写入：
[Service]
User=root
然后 sudo systemctl restart rr-nexus。

3. 验证 iptables 可用：
iptables -L INPUT -n --line-numbers | head -20
能看到规则列表即正常。

4. 测试面板通道：
rr --fw-ports
能输出 JSON 端口清单即完成授权。

说明：面板只允许操作脚本白名单内的端口（节点端口 / 订阅端口 / SSH / 面板端口），其他端口一律拒绝，防止误操作。
